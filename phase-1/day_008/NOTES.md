# Day 8 — Targeted Correlation Analysis

## What I Built
- Loaded the Diabetes dataset using Pandas.
- Selected two columns: `bmi` and `target`.
- Calculated the Pearson correlation coefficient between the selected columns.
- Created a correlation heatmap to visualize their relationship.
- Created a scatter plot with a regression line.
- Generated individual histograms for both columns.
- Used a joint plot to visualize their relationship and distributions.
- Interpreted the correlation coefficient.

## What I Learned
- How to select specific columns for correlation analysis.
- How to calculate Pearson correlation using Pandas.
- How to visualize correlation using a heatmap.
- How to identify positive and negative linear relationships.
- How to use scatter plots and regression lines.
- How to understand data distributions using histograms.
- How to visualize two variables together using a joint plot.

## Key Findings
1. The analysis focused on two numerical columns: `bmi` and `target`.
2. The Pearson correlation coefficient measured the strength and direction of their linear relationship.
3. The scatter plot helped visualize the relationship between the two columns.
4. Histograms showed the individual distributions of both variables.
5. The heatmap provided a visual representation of their correlation.

## Data Quality Check
- Selected columns were checked for missing values.
- Numerical data types were used for correlation analysis.
- The selected data was inspected before visualization.

## Limitations
- Only two columns were selected for this analysis.
- Correlation does not imply causation.
- Pearson correlation measures linear relationships only.
