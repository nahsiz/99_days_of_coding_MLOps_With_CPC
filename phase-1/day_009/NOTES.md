# Day 9 — Targeted Correlation Analysis

## What I Built
- Loaded the Student Performance dataset using Pandas.
- Selected two numerical columns: `study_hours` and `exam_score`.
- Calculated the Pearson correlation coefficient between the selected columns.
- Created a correlation heatmap to visualize their relationship.
- Created a scatter plot with a regression line.
- Generated individual histograms for both columns.
- Used a joint plot to visualize their relationship and individual distributions.
- Interpreted the correlation coefficient to identify the direction of the linear relationship.

## What I Learned
- How to select two specific columns for correlation analysis.
- How to calculate Pearson correlation using Pandas.
- How to visualize correlation using a heatmap.
- How to identify positive and negative linear relationships.
- How to use scatter plots and regression lines.
- How to understand individual data distributions using histograms.
- How to visualize two variables together using a joint plot.

## Key Findings
1. The analysis focused on the relationship between `study_hours` and `exam_score`.
2. The Pearson correlation coefficient provided a numerical measure of their linear relationship.
3. The scatter plot and regression line helped visualize the relationship.
4. Histograms showed the individual distributions of both selected columns.
5. The heatmap provided a visual representation of the correlation coefficient.

## Data Quality Check
- Selected columns were checked for missing values.
- Numerical data types were used for correlation analysis.
- The selected data was inspected before visualization.

## Limitations
- Only two columns were selected for this analysis.
- Correlation does not imply causation.
- Pearson correlation measures linear relationships and may not capture nonlinear patterns.
